# QA Call Flow Report

Дата проверки: 2026-03-18

Репозиторий: `https://github.com/DmitryGolub/golubator_tgbot`

Автотесты: `tests/test_call_flow_qa.py`

## Что было проверено

1. Регистрация ученика через `/start`.
2. Завершение активного созвона ментором через существующий callback `mentor_end_call`.
3. Поведение при завершении созвона, когда активного созвона нет.
4. Наличие пользовательских точек входа для старта и завершения созвона.
5. Наличие возможности у ученика завершить созвон через пользовательский интерфейс.

## Что работает корректно

- Обработчик `/start` создаёт нового пользователя с ролью `student`, состоянием `greeting` и запускает планирование onboarding-уведомлений.
- Внутренняя логика callback `mentor_end_call` корректно завершает активный созвон, если активная запись в `calls` уже существует.
- Если у ментора нет активного созвона, callback возвращает ожидаемый текст: `У вас нет активного созвона.`
- В student-меню нет элементов управления для завершения созвона, то есть ученик не может закрыть созвон через обычный UI.

## Найденные проблемы

1. Не реализован пользовательский сценарий старта созвона.
   В коде нет кнопки или команды, через которую ментор может начать активный созвон и создать запись в таблице `calls`.

2. Не реализована команда `/end_call`, указанная в QA-сценарии.
   В проекте есть только callback `mentor_end_call`, но message-handler с `Command("end_call")` отсутствует.

3. Существующий callback завершения созвона недоступен из интерфейса ментора.
   В клавиатуре `src/bot/handlers/common/menu.py::_mentor_meetings_menu_kb` нет кнопки с `callback_data="mentor_end_call"`.

4. Установка проекта через `pip install -e .` не работает.
   В `pyproject.toml` указан `readme = "README.md"`, но файла `README.md` в репозитории нет. Это ломает сборку метаданных пакета ещё до запуска приложения.

5. `pyproject.toml` не содержит зависимость `fastapi`, хотя существующие API-тесты и модуль `src/api/main.py` её требуют.
   Без ручной установки `fastapi` полный `pytest` падает ещё на этапе collection.

## Итог

Базовый сценарий в текущем виде не проходит целиком.

- Регистрация ученика работает.
- Завершение активного созвона работает только на уровне скрытого callback, если запись о созвоне уже создана вручную или сторонним кодом.
- Пользовательский старт созвона отсутствует.
- Завершение через `/end_call` отсутствует.
- Полный suite после ручной довстановки зависимостей: `24 passed, 2 xfailed`.

Итоговая оценка: логика частично готова на уровне внутренних обработчиков, но пользовательский call flow не доведён до рабочего состояния.

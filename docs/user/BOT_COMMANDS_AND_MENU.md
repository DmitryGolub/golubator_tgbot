# Команды и меню

## Команды

| Команда | Что видит и делает пользователь |
|---|---|
| `/start` | Начинает работу с ботом. Бот приветствует пользователя, запоминает его и показывает доступные возможности. |
| `/menu` | Открывает главное меню с кнопками, доступными для роли пользователя. |
| `/help` | Помогает вернуться к понятному списку действий. Обычно показывает меню или подсказки. |
| `/end_call` | Завершает активный созвон, если у пользователя есть такая возможность. |

## Главное меню

Меню выглядит как набор кнопок. У разных пользователей набор кнопок отличается.

### «Пользователи»

Раздел для администраторов. Позволяет найти человека, посмотреть карточку, изменить данные, роль, ментора или стадию.

### «Когорты»

Раздел для работы с группами и стадиями. Через него удобно вести движение менти по этапам.

### «Опросы»

Раздел для создания и отправки опросов. Здесь можно подготовить вопросы, включить или выключить опрос, отправить его нужным людям и посмотреть ответы.

### «Триггеры»

Раздел автоматических правил. Пользователь настраивает, когда бот должен сам отправить опрос или уведомление: например, после завершения созвона или по расписанию.

### «Роли»

Раздел для управления тем, какие действия доступны разным группам пользователей.

### «Статистика менторов»

Раздел со статистикой по менторам: активность, оценки, количество встреч и другие показатели.

### «Менти»

Раздел ментора со списком его менти. Из него можно перейти к информации о человеке и действиям по сопровождению.

### «Созвоны»

Раздел встреч. Ментор может создать созвон, выбрать участников, время, описание и ссылку. Менти видит свои встречи и может предложить встречу ментору.

### «Менти направления»

Раздел для ответственных за направление. Показывает менти, относящихся к этому направлению.

### «Отчеты: поиск работы»

Раздел с отчетами по направлению поиска работы.

### «Обратная связь: сопровождение»

Раздел с обратной связью по процессу сопровождения и обучения.

### «Моя реферальная ссылка»

Показывает персональную ссылку, которой пользователь может поделиться.

### «Канальные ссылки»

Раздел для создания ссылок для каналов и просмотра переходов по ним.

### «Обратная связь / Баг»

Позволяет отправить обращение, идею, проблему или баг. Можно приложить текст, фото, видео или файл.

### «Календарь»

Если функция доступна, пользователь может подключить календарь. После подключения встречи могут появляться в календаре автоматически.

# Что видно в Grafana

Grafana показывает руководителям, администраторам и ответственным общую картину: как проходят встречи, как заполняются опросы, как работают менторы, где возникают риски и откуда приходят новые пользователи.

## «Созвоны»

Показывает активность по встречам:

- сколько созвонов проходит за выбранный период;
- какие менторы проводят больше всего встреч;
- как созвоны распределяются по стадиям менти;
- насколько регулярно менторы встречаются с менти;
- сколько встреч в среднем приходится на разные стадии.

Этот экран помогает понять, идет ли сопровождение регулярно и где может не хватать контакта.

## «Менторы»

Показывает общую картину по менторам:

- сколько менти у каждого ментора;
- сколько созвонов проводит каждый ментор;
- какие средние оценки получают менторы;
- как меняется активность по неделям.

Этот экран помогает видеть нагрузку и качество работы менторов.

## «Профиль ментора»

Карточка выбранного ментора. В ней видно:

- сколько у ментора менти;
- сколько созвонов прошло за период;
- среднюю оценку;
- сколько опросов заполнено;
- список менти;
- оценки по вопросам;
- историю оценок.

Удобно для разбора работы конкретного ментора.

## «Профиль менти»

Карточка выбранного менти. В ней видно:

- кто назначен ментором;
- текущую стадию;
- балл/оценку менти, если она ведется;
- сколько было созвонов;
- статус контракта;
- как встречи распределялись по стадиям;
- историю переходов по стадиям.

Этот экран помогает понять путь конкретного человека.

## «Опросы»

Показывает, как пользователи отвечают на опросы:

- сколько опросов отправлено;
- какой процент заполнен;
- сколько времени занимает заполнение;
- как меняется заполняемость по неделям;
- какие статусы у опросов;
- средние оценки;
- оценки по отдельным вопросам;
- распределение оценок;
- текстовые ответы.

Этот экран помогает быстро увидеть качество обратной связи и проблемные места.

## «Аналитика обратной связи»

Показывает сигналы, на которые стоит обратить внимание:

- низкие оценки;
- важные уведомления за период;
- шаблоны с ухудшающейся динамикой;
- заполняемость разных типов опросов;
- случаи, где ответы разных участников сильно расходятся;
- ситуации, которые требуют реакции ответственного.

Этот экран нужен для контроля качества сопровождения.

## «Воронка стадий»

Показывает движение людей по стадиям:

- сколько людей находится на каждой стадии;
- как люди переходят между стадиями;
- где теряется больше всего людей;
- сколько времени в среднем занимают стадии.

Этот экран помогает понимать путь менти и находить узкие места.

## «Источники лидов»

Показывает, откуда приходят новые пользователи:

- сколько пришло по реферальным ссылкам;
- сколько пришло из каналов;
- сколько пришло без источника;
- как меняются регистрации по источникам;
- кто приводит больше всего людей;
- как разные источники проходят стадии.

Этот экран помогает оценивать эффективность рефералов и каналов.

## «Состояние сервиса»

Этот экран нужен администраторам, чтобы понимать, работает ли бот стабильно. В нем видно:

- доступен ли бот;
- есть ли проблемы у фоновых процессов;
- не растет ли количество ошибок;
- есть ли предупреждения;
- насколько активно идут фоновые действия;
- последние сообщения об ошибках и предупреждениях.

Обычным пользователям этот экран обычно не нужен. Он помогает команде поддержки быстрее заметить проблему и разобраться, почему бот может отвечать медленнее или работать нестабильно.

# Как настраивать пользователей, роли и когорты

Этот раздел предназначен для администраторов и ответственных, которые ведут пользователей и доступы в боте.

## Откуда берутся данные

Бот не является единственным местом, где живут данные. Часть списков приходит из Notion, а часть создается в самом боте.

| Данные | Откуда берутся |
|---|---|
| Менторы | Обычно из Notion. После запуска `/start` Telegram-аккаунт связывается с карточкой человека. |
| Менти | Обычно из Notion. Если менти еще не запускал `/start`, он может быть виден по данным из Notion, но без полноценной Telegram-связки. |
| Связь «ментор — менти» | Обычно из Notion. В боте ее можно поменять, если у пользователя есть доступ. |
| Статусы, направления, потоки и другие когорты | Из Notion. В боте они отображаются как типы когорт и значения внутри них. |
| Значения когорт | Из Notion. Например: «Python», «Frontend», «Активный», «В поиске работы». |
| Роли и доступы | Настраиваются в боте. Они определяют, какие кнопки и разделы видит пользователь. |
| Telegram-данные пользователя | Появляются после запуска `/start`: имя, username и связь с Telegram-аккаунтом. |

Если нужного значения нет в боте, сначала проверьте, есть ли оно в Notion. После изменения в Notion данные могут появиться в боте не мгновенно — иногда нужно дождаться обновления.

## Пользователи

### Как открыть список пользователей

1. Отправьте `/menu`.
2. Нажмите «Пользователи».
3. Бот покажет список пользователей.
4. Выберите нужного человека из списка.

В карточке пользователя обычно видно:

- имя;
- username, если он есть;
- роль;
- ментор;
- состояние или стадия;
- направления или группы;
- дата регистрации.

Имя, ментор, стадия, направление и другие признаки могут приходить из Notion. Username появляется после того, как пользователь запустил бота в Telegram.

### Как изменить пользователя

1. Откройте «Пользователи».
2. Нажмите кнопку редактирования или «Обновить».
3. Выберите пользователя.
4. Выберите, что хотите изменить:
   - «Обновить статус»;
   - «Обновить роль»;
   - «Обновить ментора»;
   - «Обновить когорту».
5. Выберите новое значение из списка.
6. Дождитесь сообщения бота об успешном обновлении.
7. Вернитесь в карточку пользователя и проверьте изменения.

### Как назначить или сменить роль пользователя

1. Откройте карточку пользователя.
2. Нажмите «Обновить роль».
3. Выберите новую роль из списка.
4. Проверьте подтверждение от бота.

После смены роли у пользователя может измениться меню: появятся новые разделы или исчезнут старые.

### Как назначить или сменить ментора

1. Откройте карточку пользователя.
2. Нажмите «Обновить ментора».
3. Выберите ментора из списка.
4. Проверьте подтверждение от бота.

Если нужного ментора нет в списке, сначала убедитесь, что он добавлен в бот и имеет роль ментора.

### Как назначить пользователю когорту или стадию

1. Откройте карточку пользователя.
2. Нажмите «Обновить когорту».
3. Выберите тип когорты: например, направление, поток или статус.
4. Выберите значение внутри этого типа.
5. Проверьте подтверждение от бота.

## Роли

Роль определяет, какие разделы и действия пользователь видит в меню.

### Как посмотреть роли

1. Откройте `/menu`.
2. Нажмите «Роли».
3. Бот покажет список ролей.
4. Выберите роль, чтобы открыть ее карточку.

В карточке роли видно:

- название роли;
- сколько пользователей к ней относится;
- какие действия доступны этой роли.

### Как создать роль

1. Откройте «Роли».
2. Нажмите «Создать роль».
3. Если бот просит короткое имя, введите его латиницей, например `senior_mentor`.
4. Введите понятное название роли, например «Старший ментор».
5. Дождитесь сообщения, что роль создана.
6. Откройте роль и настройте доступы.

Короткое имя нужно боту для сохранения роли. Пользователям обычно важно понятное название роли.

### Как настроить доступы роли

1. Откройте «Роли».
2. Выберите нужную роль.
3. Нажмите «Управление доступами».
4. Включите нужные возможности и разделы.
5. Выключите то, что роли не должно быть доступно.
6. Вернитесь к карточке роли и проверьте список доступов.

После изменения доступов меню пользователей с этой ролью может измениться.

### Как удалить роль

1. Откройте «Роли».
2. Выберите роль.
3. Нажмите «Удалить роль».
4. Подтвердите удаление.

Если бот сообщает, что роль нельзя удалить, значит к ней привязаны пользователи. Сначала назначьте этим пользователям другую роль, затем повторите удаление.

## Когорты

Когорты помогают группировать пользователей. Например, это может быть направление, поток, статус или этап обучения.

Когорты берутся из Notion. В боте администратор видит их как справочник, может добавлять, переименовывать и удалять значения, если это разрешено.

Простыми словами:

- тип когорты — это категория из Notion, например «Направление» или «Статус»;
- опция — это конкретное значение внутри категории, например «Python», «Frontend», «Активный», «В поиске работы».

### Как посмотреть когорты

1. Откройте `/menu`.
2. Нажмите «Когорты».
3. Выберите тип когорты.
4. Бот покажет значения внутри выбранного типа.

### Как создать тип когорты

1. Откройте «Когорты».
2. Нажмите «Создать тип».
3. Введите название типа, например «Направление».
4. Дождитесь подтверждения.
5. Проверьте, что новый тип появился в списке.

### Как добавить значение в когорту

1. Откройте «Когорты».
2. Выберите нужный тип.
3. Нажмите «Добавить опцию».
4. Введите новое значение.
5. Дождитесь подтверждения.
6. Проверьте, что значение появилось в списке.

Новое значение добавляется в общий справочник Notion и после этого становится доступно для выбора пользователям.

### Как переименовать значение

1. Откройте «Когорты».
2. Выберите тип когорты.
3. Нажмите «Переименовать опцию».
4. Выберите значение.
5. Введите новое название.
6. Проверьте подтверждение от бота.

### Как удалить значение

1. Откройте «Когорты».
2. Выберите тип когорты.
3. Нажмите «Удалить опцию».
4. Выберите значение.
5. Подтвердите удаление, если бот попросит.

Перед удалением убедитесь, что это значение больше не нужно пользователям и отчетам. Удаление значения влияет на общий справочник в Notion.

### Как переименовать тип когорты

1. Откройте «Когорты».
2. Выберите тип.
3. Нажмите «Переименовать тип».
4. Введите новое название.
5. Проверьте подтверждение.

### Как удалить тип когорты

1. Откройте «Когорты».
2. Выберите тип.
3. Нажмите «Удалить тип».
4. Подтвердите действие, если бот попросит.

Удаление типа влияет на все значения внутри него, поэтому используйте это действие осторожно.

## Если нужной кнопки нет

- Если вы не видите «Пользователи», «Роли» или «Когорты», значит раздел не доступен вашей роли.
- Если в списке нет нужного человека, сначала попросите его запустить `/start`.
- Если в списке нет нужного ментора, проверьте, что у пользователя назначена роль ментора.
- Если нет нужной когорты, сначала создайте тип или значение в разделе «Когорты».
